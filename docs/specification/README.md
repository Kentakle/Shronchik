# Shronchik — документация проекта

Проектная документация персональной локальной медиатеки для Windows 11.

- **Shronchik_Technical_Spec_v1.1.md** — подробное техническое задание, архитектура, дизайн, безопасность, алгоритмы, API, тесты и 15 этапов разработки.
- **assets/** — исходные эскизы интерфейса владельца и диаграммы архитектуры/импорта.

Статус: **спецификация, не готовая программа**. В документе согласованные требования отделены от предлагаемых технических решений и пунктов, требующих утверждения.

## Важные предупреждения

- Начальные пароли `1111` удобны, но небезопасны для защиты частной медиатеки: их необходимо менять.
- Без recovery-ключей зашифрованные данные могут быть невосстановимы после потери паролей или переустановки системы.
- RAID/NAS не заменяет резервную копию.
- Данные и реальные медиа не добавляются в публичный GitHub.

Документация: 04.11.2026, v1.1.
